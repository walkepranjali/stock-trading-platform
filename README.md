Stock Trading Platform

A Zerodha-Inspired Stock Trading Platform built using the MERN stack. This project aims to recreate the experience of a modern online trading platform through a web-based interface for exploring market information and managing trading-related activities.

Overview

The Stock Trading Platform is a full-stack web development project inspired by the user experience of Zerodha. It is intended to demonstrate frontend development, backend integration, and database-driven application development in a financial technology context.

The project is organized into separate frontend, backend, and dashboard components to support a structured development workflow.

Tech Stack

Frontend: JavaScript, SCSS

Backend: Node.js and Express.js (MERN-stack backend)

Database: MongoDB

Architecture: Full-stack web application

Project Structure

Getting Started

Prerequisites

Install the following tools before running the project:

Node.js and npm

Git

MongoDB, if required by the application

1. Clone the Repository

git clone https://github.com/walkepranjali/stock-trading-platform.git
cd stock-trading-platform

2. Install Dependencies

Install dependencies in the directories that contain a package.json file:

cd backend
npm install

Repeat the installation for frontend and dashboard as applicable.

3. Configure Environment Variables

Create the appropriate .env file based on the existing environment configuration and provide the required values, such as database connection details and server port.

Security: Do not commit .env files, API keys, database credentials, or other secrets to GitHub.

4. Run the Application

Check the scripts section of each directory's package.json to identify the correct development and start commands.

For example, if the project defines these scripts:

npm run dev

or

npm start

Run the appropriate command from the relevant directory.
