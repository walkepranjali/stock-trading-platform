# Stock Trading Platform

A full-stack stock trading platform with frontend, dashboard, and backend services.

## Architecture & Structure

- **`frontend/`**: Public landing page and user application built with React.
- **`dashboard/`**: Trading and analytics dashboard for managing portfolio, holdings, positions, and orders.
- **`backend/`**: Node.js & Express REST API powered by MongoDB for persisting holdings, positions, and orders.

## Getting Started

### 1. Backend
```bash
cd backend
npm install
npm start
```

### 2. Frontend
```bash
cd frontend
npm install
npm start
```

### 3. Dashboard
```bash
cd dashboard
npm install
npm start
```
